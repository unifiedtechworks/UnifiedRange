# Inter font asset

UnifiedRange bundles the upright Inter variable webfont so production builds do not depend on a build-time request to Google Fonts.

- Upstream project: [rsms/inter](https://github.com/rsms/inter)
- Release: [Inter v4.1](https://github.com/rsms/inter/releases/tag/v4.1)
- Asset: `web/InterVariable.woff2`
- Supported style/weight range: normal, 100–900
- Asset SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`
- Release archive SHA-256: `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`
- License: SIL Open Font License 1.1; see `Inter-LICENSE.txt`

Only the upright variable WOFF2 used by the app is included. The italic asset and the remainder of the release archive are intentionally omitted.
